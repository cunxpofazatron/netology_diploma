# API для автоматизации закупок розничной сети

Дипломный проект по профессии "Python-разработчик". Представляет собой backend-приложение (API) для интернет-магазина, автоматизирующее процессы закупки товаров у поставщиков и продажи их покупателям.

## Стек технологий
* **Язык и фреймворки:** Python 3.12, Django 6.1, Django REST Framework
* **База данных:** PostgreSQL
* **Асинхронные задачи и кэш:** Celery, Redis
* **Инфраструктура:** Docker, Docker Compose
* **CI/CD и качество кода:** GitHub Actions, Flake8
* **Документация:** drf-spectacular (Swagger/OpenAPI)

## Основной функционал
* **Пользователи и безопасность:** Кастомная модель пользователя, регистрация и авторизация по токенам. Защита API от спама (Throttling) и скрытие секретов в `.env`.
* **Каталог товаров:** Загрузка каталога из YAML-файлов, фильтрация по категориям и магазинам. Кэширование частых запросов с помощью Redis для ускорения ответа.
* **Заказы и корзина:** Управление корзиной (добавление, просмотр, удаление позиций), управление адресами доставки, оформление заказа.
* **Фоновые задачи:** Автоматическая **асинхронная** отправка email-уведомлений при изменении статуса заказа и регистрации (выполнено через Celery).
* **DevOps:** Полная контейнеризация инфраструктуры (4 сервиса: `web`, `db`, `redis`, `celery`) и настроенный CI/CD пайплайн (автотесты и линтер при каждом push-запросе).

## Запуск проекта (Docker)

Проект настроен для быстрого развертывания в изолированных контейнерах. Локальная установка библиотек не требуется.

### 1. Подготовка окружения
Клонируйте репозиторий и перейдите в папку проекта:
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ПАПКА_ПРОЕКТА>
```

Создайте файл с переменными окружения из предоставленного шаблона:
```bash

cp .env.example .env
```

(При необходимости отредактируйте .env, указав свои пароли)
### 2. Запуск контейнеров

Соберите и запустите инфраструктуру в фоновом режиме:
```bash

sudo docker-compose up -d --build
```

### 3. Применение миграций

Примените структуру базы данных внутри контейнера web:
```bash

sudo docker-compose exec web python manage.py migrate
```

### 4. Создание администратора

Создайте суперпользователя для доступа в панель управления:
```bash

sudo docker-compose exec web python manage.py createsuperuser
```

### 5. Документация API

После успешного старта контейнеров интерактивная документация Swagger UI (с возможностью отправки тестовых запросов) будет доступна по адресу:
http://127.0.0.1:8000/api/schema/swagger-ui/

Панель администратора Django:
http://127.0.0.1:8000/admin/
