# Backend-приложение для автоматизации закупок

Дипломный проект по созданию API для интернет-магазина: закупки товаров у поставщиков и продажа товаров покупателям.

## Стек технологий

* Python 3.12
* Django 6.1
* Django REST Framework
* PostgreSQL
* Docker
* Docker Compose

## Реализованный функционал

* Кастомная модель пользователя.
* Регистрация и авторизация по токенам.
* Загрузка каталога товаров из YAML-файлов.
* Фильтрация товаров по категориям и магазинам.
* Корзина покупателя:

  * добавление товаров;
  * просмотр содержимого;
  * удаление позиций.
* Оформление заказа.
* Управление адресами доставки.
* Автоматическая отправка email-уведомлений при изменении статуса заказа.
* В режиме разработки email-уведомления выводятся в консоль.
* Полная контейнеризация приложения и базы данных.

## Запуск проекта через Docker

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ПАПКА_ПРОЕКТА>
```

### 2. Запуск проекта

```bash
docker-compose up -d
```

После запуска API будет доступно по адресу:

```text
http://127.0.0.1:8000/api/v1/
```

## Локальный запуск

### 1. Установка зависимостей

Активируйте виртуальное окружение и установите зависимости:

```bash
pip install -r requirements.txt
```

### 2. Настройка базы данных

Для локального запуска необходимо наличие PostgreSQL.

При необходимости можно закомментировать блок настройки PostgreSQL в `settings.py` и использовать SQLite.

### 3. Применение миграций

```bash
python manage.py migrate
```

### 4. Запуск сервера

```bash
python manage.py runserver
```

После запуска API будет доступно по адресу:

```text
http://127.0.0.1:8000/api/v1/
```
